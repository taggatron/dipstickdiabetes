# Dipstick Diabetes Simulation Lab

A tiny browser-based simulation to practise interpreting urine dipstick results for diabetes-related scenarios. Includes three virtual patients, animated dipping, and bright, high-contrast styling for teaching.

## Files

- `index.html` – main entry page.
- `style.css` – bright, accessible styling and animations.
- `main.js` – patient logic and dipstick behaviour.

## Run locally

No build tools are required.

1. Open this folder in VS Code.
2. Use the built-in **Live Server** (if installed) or simply open `index.html` in your browser:
   - Finder: double-click `index.html`, or
   - Terminal:

```bash
cd "/Users/danieltagg/Desktop/Desktop - Daniel’s MacBook Pro/dipstickdiabetes"
open index.html
```

## How to use

1. Choose one of the three virtual patients on the left.
2. Click **Dip Strip** to animate dipping the stick into the beaker.
3. Watch each pad change colour and check the legend.
4. Read the results and clinical reasoning panels on the right.

> Educational use only – not for diagnostic or treatment decisions.
